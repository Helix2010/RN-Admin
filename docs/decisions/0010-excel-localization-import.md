# ADR-0010：管理端使用 SheetJS 处理多语言 Excel

- 状态：Accepted
- 日期：2026-08-26

## 决策

多语言管理页使用维护中的 `@e965/xlsx`（SheetJS 社区维护分支）在浏览器本地完成 Excel 导入预览和导出。导入只合并非空单元格，空值不会隐式删除租户文案；用户确认后仍由 RN-Server 校验语言编码、Key、长度和租户归属。

## 取舍

该依赖增加管理端独立 Excel chunk 体积；换取无需服务端临时文件、可直接预览和复用 Excel 模板。依赖采用社区维护分支以避免已知高危漏洞；能力通过动态 import 加载，不影响首屏主包。
