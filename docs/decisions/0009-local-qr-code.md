# ADR 0009：管理端本地生成安装二维码

## 状态

已采用

## 背景

发布管理需要让测试人员使用手机扫码安装 APK。二维码必须编码当前租户的公开 HTTPS 下载地址，不能依赖第三方二维码图片服务，也不能把对象存储凭证或私有地址放入二维码。

## 决策

管理端使用 MIT 协议的 `qrcode` 轻量依赖在浏览器本地生成 PNG Data URL，并在分享弹窗中同时提供复制链接和直接下载。二维码只包含服务端公开下载 endpoint；安装包仍由 RN-Server 做租户、发布状态和对象存储校验。

## 备选方案

- 第三方二维码 URL：实现简单，但依赖外部服务、存在可用性和隐私边界，不采用。
- 自行实现 QR 编码器：减少依赖，但维护和正确性风险高，不采用。

## 影响与退出

新增前端依赖体积较小，不引入原生影响。若未来宿主提供统一二维码能力，可移除 `qrcode` 并保留分享弹窗契约。
